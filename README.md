## 🎯 Sobre o Projeto

**Full Stack Games** é uma aplicação que permite aos usuários gerenciar sua coleção pessoal de jogos. O projeto foi desenvolvido como parte do curso de DSM da FATEC, demonstrando conceitos de desenvolvimento full stack com Flask, blueprints, validação de dados com Pydantic, e documentação de API com Swagger.

### Motivação

Como um gamer apaixonado, sempre quis ter um lugar para registrar os jogos que já joguei, minhas notas pessoais e status de conclusão. Este projeto nasceu dessa necessidade e evoluiu para uma aplicação completa e funcional.

## ✨ Funcionalidades

- ✅ **Listar jogos** - Visualize todos os jogos da sua coleção
- ✅ **Adicionar jogos** - Cadastre novos jogos com nome, gênero, plataforma, ano e nota
- ✅ **Remover jogos** - Delete jogos da sua coleção
- ✅ **Buscar por ID** - Consulte um jogo específico
- ✅ **Validação de dados** - Campos validados com Pydantic
- ✅ **Documentação Swagger** - API totalmente documentada
- ✅ **Interface responsiva** - Design adaptável com TailwindCSS
- ✅ **Landing page** - Página estática apresentando o projeto

## 🛠 Tecnologias Utilizadas
