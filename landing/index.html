🎮 Games App

Organize sua coleção de jogos de forma simples

Como usar

Sobre o projeto

Games App é uma aplicação completa para você gerenciar sua biblioteca de jogos. Com ela você pode adicionar, listar e remover jogos da sua coleção.

Como executar

1. Backend

cd backend
pip install -r requirements.txt
python app.py

🔗 API: http://localhost:5000

📖 Swagger: http://localhost:5000/api/docs

2. Frontend

cd frontend
# Use um servidor HTTP
python -m http.server 5500

🌐 Frontend: http://localhost:5500

🎮 Games App - Sua coleção organizada
